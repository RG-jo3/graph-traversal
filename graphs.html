    Concepts, types and operations
    

    What is a graph?A graph G = (V, E) is a set of vertices (nodes) connected by edges. Two vertices joined by an edge are adjacent; the number of edges at a vertex is its degree. A path is a sequence of vertices joined by edges.
    

    Types of graphsUndirected (edges go both ways) vs directed / digraph (edges have a direction). Toggle “Directed” to see how traversal changes. This tool stores graphs as an adjacency list; the alternative is an adjacency matrix.
    

    Breadth-First Search (BFS)Explores level by level using a queue (FIFO). Finds the shortest path in an unweighted graph. Time O(V+E), space O(V).
    

    Depth-First Search (DFS)Goes as deep as possible before backtracking using a stack (LIFO) or recursion. Time O(V+E), space O(V). Neighbours are explored in alphabetical order. Green edges show the traversal tree.
    

    Practical applicationsBFS: shortest routes in maps/networks, social-network “degrees of separation”, web crawlers, network broadcasting. DFS: cycle detection, topological sorting (task/build dependencies), maze solving, connected components, file-system traversal.
    

    Test cases to try (normal, boundary, invalid)
Normal: Sample graph, BFS from A → A B C D E F H G; DFS from A → A B D E G C F H.
Boundary: single node; no edges; disconnected graph; cycle; target = start; target not in graph.
Invalid: self-loop (A-A), duplicate edge, edge to a missing node, malformed text such as “AB”.
